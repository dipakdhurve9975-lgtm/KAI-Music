# KAI Music 1.4.9 — preview candidate

This is a debug-signed Universal GMS preview, version code 170. It keeps the existing preview package and signing identity. It is not a stable production release.

## Changes

- Fix a frozen lyric timeline caused by a retained callback capturing the initial hidden state before synchronized lyrics finished loading. Real audio timestamps again advance the active line and automatic scrolling.
- Preserve existing lyric fonts, styles, original-script text, providers, saved offsets, seeking and playback state.
- Add KAI-only update checks, an optional release-notes dialog, explicit download progress/cancel/retry, APK verification and Android's installation handoff. Stable is the default; previews require opt-in.
- Generate updater metadata from the inspected APK, signing certificate and exact committed source. Existing 1.4.8 installations need one manual compatible update to receive the updater.
- Place the current download at the top of the README. Keep creator/project GitHub credits there; Instagram remains inside About only.

## Verification and limits

The focused lyric repair was tested on the connected A001: active-line progression, rendered scrolling, paused seeking, resume, Normal/Lyrics switching, track change and foreground return. Its Compose runtime regression tests pass. The final combined build and updater test results are recorded in the accompanying engineering report.

Updates never use Echo Music's APK feed. Package, version code, Android/ABI compatibility, byte count, checksum and installed signing identity must match before Android can request installation. No silent installation or data clearing occurs. Hosted signing automation still requires the maintainer's existing keystore and repository configuration; a new key must not be generated as a substitute.

An end-to-end in-app upgrade to a newer public release requires that approved newer release to exist. Broader device/asset/native/GMS license reviews and production signing decisions remain open; this candidate is not a guarantee of complete security or legal clearance.

Source, build scripts, checksums, build metadata and release metadata accompany an approved release. Original Echo Music and third-party licenses/notices remain.
