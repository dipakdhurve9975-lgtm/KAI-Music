# KAI Music 1.4.10 Preview

Universal GMS debug preview, version code 171. Same application ID and signing certificate; install over the existing compatible preview without clearing data.

- Preview builds now check compatible KAI preview updates by default when the app opens. Production builds retain stable-only defaults. Explicit saved choices and dismissed release versions are respected.
- Automatic successful checks refresh after one hour; failed checks retain a thirty-minute backoff. A new/changed update channel invalidates the previous channel's cached check. Downloads and Android installation remain optional and user-approved.
- Move the original Echo Music creator's Instagram to a clearly attributed row directly below the KAI owner's Instagram in About. Keep the friend's profile below it and retain GitHub/source/contributor credits. No Instagram link is added to README.
- Keep the existing lyric synchronization repair and KAI player designs.

Existing 1.4.9 users must enable **Include preview releases** once to receive this preview through their current updater. Versions 1.4.8 and earlier have no KAI updater and need a one-time manual installation. A download link cannot retrofit notifications into older binaries or identify/contact anonymous downloaders. New downloads of this build use the compatible preview channel by default, unless the user explicitly opts out.

This remains a preview. Existing stable-readiness and licensing review limits remain documented in the project reports.
