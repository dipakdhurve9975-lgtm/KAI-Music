# KAI Music 1.4.8 — preview candidate

KAI Music is an independent modification of Echo Music.

## What's new

- About separates Echo Music origins, Aditya's original work, original contributors and independent KAI development. Existing KAI maintainer/friend/support links remain.
- About includes offline GPL and bundled notices, with source/original-project links. Longer acknowledgments expand on demand.
- Updates opens the KAI releases page only when tapped. No background release checking, notification or automatic APK download is reintroduced.
- Source/documentation and draft-release tooling are prepared for review, with stable/preview separation, signature validation and matching source/checksums.

## Licensing and build changes

- Replaced the inherited restricted Google Sans Flex binary with the official OFL edition at the same Android resource ID; added missing font/Apache license texts and dated modification notices.
- Removed inherited hardcoded Last.fm credentials from build scripts. This optional integration requires the maintainer's own configuration; credentials are not supplied in the public build. Other playback/library features are unchanged by this task.
- Version 1.4.8 (169); Universal GMS debug preview; Android 8.0+; application ID `echo.music.iad1tya.debug`. Keep the existing preview signing identity for updates. This is not a production stable build.

## Verification

See the accompanying review/verification report for actual commands and results. Connected-device regression checks, including live lyric progression inherited from 1.4.7, remain required before claiming runtime success.
